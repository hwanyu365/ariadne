# 수집 스펙

## 1. 개요

| 항목 | 값 |
| --- | --- |
| 문서명 | ariadne 수집 (UC1·UC2) |
| 작성일 / 최종 수정일 | 2026-11-14 / 2026-11-14 |
| 버전 | 1.0 |
| 기준 커밋 ID | 1cd7b71 |

- **기능명:** 페이지 순회와 본문 텍스트·이미지 저장 (`scrape`)
- **목적 (Why):**
  - 한 편이 여러 페이지로 나뉜 연재물을 사람이 next 를 누르지 않고 끝까지 받는다
  - 텍스트(UC1)와 이미지(UC2)는 순회·중단 판정·저장 규칙을 공유한다 → 한 파일에 둔다
  - 문제가 생기는 구조: 수집 대상은 원격 페이지가 정한다 → 셀렉터 오타·지연 렌더·SPA·차단 응답·순환 링크가 모두 "조용히 1페이지만 받거나 끝없이 받는" 실패로 나타난다

## 2. 목표 및 범위

### In Scope

- 링크 이동·SPA 의 next 를 눌러 마지막 페이지까지 넘긴다
- 페이지마다 본문 텍스트(txt) 또는 이미지 파일을 즉시 저장한다
- 멈출 때 사유와 이어 받을 위치를 로그에 남긴다
- 인코딩 오판 경고와 인코딩 지정

### Out of Scope

- 색인 `docs/specification.md` 제외 범위를 따른다
- 셀렉터 찾기(probe·선택기) → `docs/spec_selector.md`
- 창·설정 저장 → `docs/spec_window.md`

## 3. 요구사항

### 3.1 사용자 스토리

- `US#1` 연재물을 받는 사용자로서, next 를 수백 번 누르지 않기 위해, URL·셀렉터만 넣고 본문 텍스트를 끝까지 받기를 원한다 [요구사항] → FR#1~FR#12
- `US#2` 이미지 연재물을 받는 사용자로서, 글이 아닌 회차도 받기 위해, 같은 입력으로 페이지별 이미지를 받기를 원한다 [요구사항] → FR#13~FR#16
- `US#3` 사용자로서, 낯선 사이트를 수집해도 PC 가 안전하기 위해, 수집 창의 원격 페이지가 앱과 로컬 파일에 닿지 않기를 원한다 [요구사항] → FR#17~FR#18

### 3.2 기능 요구사항

- `FR#1` next 를 누른 뒤 수집 대상이 바뀌어 안정될 때까지 기다렸다가 다음 페이지로 본다 [as-built] (`NFR#1`)

  ```
  Given  링크로 넘어가는 페이지, 또는 URL 이 그대로이고 JS 로 본문만 바꾸는 SPA
  When   수집을 시작한다
  Then   마지막 페이지까지 페이지마다 파일 하나가 생긴다
  Given  next 위를 다른 요소가 잠시 덮거나 위치가 아직 움직인다
  When   next 를 누를 차례다
  Then   위치가 멈추고 그 자리에 next 가 있을 때 누른다
  Given  본문이 나눠 그려진다
  When   첫 변화를 본다
  Then   300ms 뒤 다시 읽어 같을 때만 저장한다 → 그리던 도중의 본문이 저장되지 않는다
  ```

- `FR#2` next 를 누를 수 없거나 눌러도 소용없으면 그 링크의 주소로 같은 탭에서 넘어간다 [as-built] (`NFR#1`)

  ```
  Given  next 가 숨김·비활성(disabled, aria-disabled)·다른 요소에 덮임이고 href 가 살아 있다
  When   다음 페이지로 넘길 차례다
  Then   href 로 이동해 계속 받는다
  Given  next 가 target=_blank 링크이거나, 셀렉터가 링크 안쪽 장식 요소를 가리킨다
  Then   감싼 링크의 주소로 같은 탭에서 넘어간다
  Given  next 가 버튼·입력 요소를 감싼 링크다
  Then   그 링크 주소를 쓰지 않는다 → 다음 페이지가 아닌 카드 전체 링크일 수 있다
  Given  href 가 '#…' 이나 javascript: 다
  Then   주소로 쓰지 않는다. 덮여서 누르지 못했으면 그 사유를, 숨김·비활성이면 마지막 페이지를 사유로 남긴다
  ```

- `FR#3` 더 넘길 수 없으면 멈추고 사유를 남긴다 [as-built] (`NFR#2`)

  ```
  Given  next 셀렉터에 걸리는 요소가 없다
  Then   셀렉터 불일치를 사유로 멈춘다
  Given  next 가 숨김·비활성이고 href 도 없다
  Then   마지막 페이지로 보고 멈춘다
  Given  next 의 주소를 해석할 수 없거나 덮여서 누르지 못했고 href 도 없다
  Then   그 사유를 남기고 멈춘다
  Given  위 사유로 첫 페이지에서 멈춘다
  Then   사유 뒤에 probe 로 확인하라는 안내를 붙인다
  Given  최대 페이지 N 을 지정했다
  Then   N 페이지를 받은 뒤 사유 줄 없이 멈춘다
  Given  next 를 누른 뒤 타임아웃 동안 수집 대상이 바뀌지 않는다
  Then   타임아웃을 사유로 멈추고 타임아웃을 늘리라고 안내한다
  Given  시작 페이지를 타임아웃 안에 열지 못하거나, 첫 페이지에서 수집 대상 셀렉터가 타임아웃 동안 걸리지 않는다
  Then   파일 없이 실패로 끝난다 (§4)
  ```

- `FR#4` 이미 받은 페이지가 다시 나오면 멈춘다 [as-built] (`NFR#1`)

  ```
  Given  마지막 페이지의 next 가 처음 페이지로 돌아간다
  Then   주소·수집 대상이 모두 같은 페이지가 다시 나온 시점에 멈춘다
  Given  다른 주소의 페이지가 앞 페이지와 같은 본문이다 (삽화·공지)
  Then   계속 받는다
  Given  주소가 그대로인 SPA 가 중간에 같은 본문을 보인다
  Then   계속 받는다
  Given  주소가 그대로인 SPA 가 첫 페이지로 돌아오거나 같은 넘어감(앞 본문 → 다음 본문)이 다시 나온다
  Then   멈춘다
  ```

- `FR#5` 시작 페이지나 next 로 받은 새 문서가 HTTP 오류면 저장하지 않고 상태 코드를 사유로 멈춘다 [as-built] (`NFR#2`)

  ```
  Given  시작 주소(이어 받기 주소 포함)가 4xx·5xx 로 응답한다
  Then   페이지 파일을 만들지 않고 상태 코드를 사유로 멈춘다
  Given  next 로 넘어간 문서가 4xx·5xx 이고, 같은 틀로 본문 자리를 채운다
  Then   그 페이지를 저장하지 않고 상태 코드를 사유로 멈춘다. 텍스트·이미지 모드 모두 같다
  ```

- `FR#6` 사용자 중지는 현재 페이지를 마친 뒤, 기다리는 중이면 그 자리에서 반영한다 [as-built] (`NFR#6`)

  ```
  Given  텍스트 페이지를 저장하는 중 중지를 누른다
  Then   그 페이지까지 저장하고 '사용자 중지' 사유로 멈춘다
  Given  이미지 페이지를 받는 중 중지를 누른다
  Then   그 페이지의 남은 이미지를 받지 않고(건너뜀으로도 남기지 않고) 멈춘다. 마지막으로 받은 페이지는 그 페이지다 → 그 번호로 다시 시작하면 그 페이지부터 다시 받는다
  Given  수집 대상이 바뀌기를 기다리거나 페이지 간 대기 중에 중지를 누른다
  Then   페이지를 하나 더 받지 않고 그 자리에서 멈춘다
  Given  next 를 누르는 중(최대 2초)이나 next 주소로 이동하는 중(최대 타임아웃)에 중지를 누른다
  Then   그 동작이 끝난 뒤 멈춘다. 페이지를 하나 더 받지는 않는다
  ```

- `FR#7` 페이지마다 `{접두사}_{번호}` 이름으로 즉시 쓰고, 멈추면 마지막으로 저장한 페이지의 번호·주소를 남긴다 [as-built] (`NFR#2`, `NFR#3`, `NFR#4`)

  ```
  Given  자릿수 D, 시작 번호 S
  Then   첫 파일은 {접두사}_{S 를 D 자리로 채운 값}.txt 다
  Given  첫 파일 이름이 이미 있다 (대소문자 무시, 이미지는 {접두사}_{번호}_ 로 시작하는 파일)
  Then   덮어쓰거나 섞일 수 있다고 경고하고 계속한다
  When   어떤 사유로든 멈춘다
  Then   '마지막으로 받은 페이지: {번호}번 {주소}' 를 남긴다 → 그 주소·번호로 다시 시작하면 이어진다
  ```

- `FR#8` 제목 셀렉터를 주면 txt 맨 앞에 `{번호}화. {제목}` 헤더를 붙인다 [as-built]

  ```
  Given  제목 셀렉터가 걸린다
  Then   첫 줄이 '{번호}화. {제목}' 이고 빈 줄 뒤에 본문이 온다
  Given  제목 셀렉터가 걸리지 않는다
  Then   경고를 남기고 '{번호}화.' 헤더로 저장을 계속한다 → 부가 정보라 수집을 멈추지 않는다
  ```

- `FR#9` 텍스트 모드는 제외 셀렉터에 걸린 요소를 뺀 본문을 저장하고, 페이지 변경 판정도 뺀 뒤의 본문으로 한다 [as-built] (`NFR#14`)

  ```
  Given  제외 셀렉터가 본문 안의 광고·댓글을 가리킨다
  Then   그 글자 없이 화면에 보이는 줄바꿈대로 저장한다. 페이지 CSP 가 인라인 스타일을 막아도 같다
  Given  제외 셀렉터 문법이 틀렸다
  Then   실패로 알리고 멈춘다
  Given  제외 셀렉터가 수집 대상이나 그 조상을 가린다 (첫 페이지 또는 이후 페이지)
  Then   실패로 알리고 멈춘다
  ```

- `FR#10` 합치기를 켜면 받은 본문을 `{접두사}_all.txt` 에도 페이지마다 이어 쓴다 [as-built] (`NFR#15`)

  ```
  Given  시작 번호 1
  Then   _all.txt 를 새로 쓰고 페이지 사이를 빈 줄 하나로 나눈다. 이미 있었으면 경고한다
  Then   새로 쓰기와 경고는 첫 페이지를 저장할 때 한다 → 시작 페이지가 오류이거나 열리지 않거나 수집 대상이 없으면 기존 _all.txt 를 그대로 둔다
  Given  시작 번호 2 이상이고 _all.txt 가 있다
  Then   지우지 않고 뒤에 이어 쓴다
  ```

- `FR#11` 원래 바이트가 비ASCII 를 담은 올바른 UTF-8 인데 브라우저가 다른 인코딩으로 읽었으면 경고한다 [as-built] (`NFR#9`)

  ```
  Given  charset 선언이 없거나 틀린 UTF-8 페이지 (첫 페이지 또는 이후 페이지)
  Then   수집 로그에 utf-8 로 지정하라는 경고를 한 번 남긴다
  Given  브라우저가 UTF-8 로 읽었거나 바이트가 ASCII 뿐이거나 올바른 UTF-8 이 아니다
  Then   경고하지 않는다
  Given  지금 문서가 바이트를 남기지 않는 오류 응답이다
  Then   지난 문서의 바이트로 판정하지 않는다
  ```

- `FR#12` 인코딩을 지정하면 메인 문서 응답의 charset 을 그 값으로 바꿔 읽는다 [as-built] (`NFR#9`)

  ```
  Given  인코딩 utf-8 을 지정했고 페이지는 선언이 없거나 다른 값을 선언했다
  Then   글자가 깨지지 않게 저장한다. gzip 응답, 다른 사이트로 넘어간 뒤 문서도 같다
  Given  응답이 쿠키를 내린다
  Then   바꿔 넘긴 뒤에도 다음 요청에 쿠키가 실린다
  Given  응답 본문을 얻지 못했다
  Then   원래 응답 그대로 읽는다 → 요청이 타임아웃까지 매달리지 않는다
  Given  페이지 안에 iframe 이 있다
  Then   iframe 문서의 인코딩은 바꾸지 않는다
  Given  알 수 없는 인코딩 이름이나 허용 문자 밖의 이름 (헤더 주입 포함)
  Then   시작 전에 거부한다. 입력 검사를 거치지 않은 호출도 엔진 입구에서 거부한다
  ```

- `FR#13` 이미지 모드는 수집 대상 이미지마다 `{접두사}_{번호}_{장번호}{확장자}` 로 저장한다 [as-built] (`NFR#4`)

  ```
  Given  페이지마다 이미지 2장
  Then   페이지마다 2개 파일이 생기고 로그에 '이미지 n장' 을 남긴다
  Given  주소가 없거나 전부 data: 인 이미지뿐이다
  Then   아무것도 저장하지 않고 '이미지 0장' 으로 남긴다 → 페이지 자체를 이미지로 받지 않는다
  ```

- `FR#14` 지연 로딩 이미지의 실제 주소를 읽는다 [as-built] (`NFR#5`)

  ```
  Given  실제 주소가 data-src, data-original, data-lazy-src 에 있다
  Then   src 보다 그 속성을 먼저 쓰고, 한 페이지 안의 같은 주소는 한 번만 받는다
  Given  본문이 스크롤 상자 안에 있다
  Then   이미지마다 화면 안으로 가져와 지연 로딩을 깨운 뒤 읽는다
  Given  스크롤이 끝나지 않는다
  Then   경고만 남기고 계속한다
  ```

- `FR#15` 받은 응답이 이미지일 때만 저장하고, 한 장의 실패가 수집을 멈추지 않는다 [as-built] (`NFR#5`)

  ```
  Given  응답이 HTML(핫링크 차단 등)이거나 image/* 이지만 마크업이다
  Then   '건너뜀' 으로 남기고 다음 장으로 간다. SVG 는 이미지로 본다
  Given  형식이 없거나 octet-stream 이다
  Then   내용으로 형식을 못 정하면 주소의 확장자가 이미지일 때만 받는다
  Given  확장자
  Then   받은 내용(시그니처)으로 정하고, 못 정하면 형식·주소로 정한다
  Given  응답이 멈춘 이미지
  Then   타임아웃 뒤 건너뛰고 나머지와 다음 페이지를 받는다
  Given  이미지 요청이 겹친다
  Then   뒤 요청을 거부한다 → 이미지별 Referer 정책이 섞이지 않는다
  ```

- `FR#16` 이미지 요청의 Referer 는 페이지가 그 이미지를 그릴 때 브라우저가 보내는 값과 같다 [as-built] (`NFR#5`, `BR#1`)

  ```
  Given  같은 출처 이미지 / 다른 출처 이미지
  Then   페이지 주소 전체 / 페이지의 출처를 보낸다 (기본 정책 strict-origin-when-cross-origin)
  Given  요소 referrerpolicy, 문서 meta referrer, Referrer-Policy 응답 헤더
  Then   그 순서로 아는 값이 든 첫 단계의 정책을 쓴다. 모르는 값만 있는 단계는 건너뛴다
  Given  이미지 요청이 리디렉션된다
  Then   단계마다 그 주소 기준으로 다시 정한다
  Given  페이지가 스스로 보낸 요청
  Then   Referer 를 바꾸지 않는다
  Given  페이지 주소에 user:pass@ 나 # 가 있다
  Then   싣지 않는다
  ```

- `FR#17` 수집 창의 원격 페이지는 새 창·권한·다운로드·로컬 주소를 얻지 못한다 [as-built] (`NFR#13`)

  ```
  Given  target=_blank 링크, window.open
  Then   창이 늘지 않는다
  Given  알림·위치·미디어 권한 요청, 다운로드
  Then   거부된다
  Given  이미지·next 주소가 file: 처럼 웹이 아닌 스킴이고 지금 페이지와 스킴이 다르다
  Then   그 이미지는 건너뛰고, href 로 넘어갈 next 는 따라가지 않는다는 사유를 남기고 멈춘다
  Given  그런 주소의 next 가 누를 수 있는 링크다
  Then   브라우저가 이동을 막는다 → 수집 대상이 바뀌지 않아 타임아웃 사유로 멈춘다
  ```

- `FR#18` 실행마다 비영속 세션을 새로 만든다 [as-built] (`NFR#11`)

  ```
  Given  앞 실행에서 사이트가 쿠키를 내렸다
  When   다음 실행을 시작한다
  Then   그 쿠키가 요청에 실리지 않는다
  ```

### 3.3 비기능 요구사항

- 색인 공통 제약 `NFR#1`~`NFR#5`, `NFR#9`, `NFR#11`, `NFR#13`~`NFR#15` 를 따른다

## 4. 데이터 및 API 스펙

- `scrape(url, sel, nextSel, prefix, options)` → 받은 페이지 수
  - 예외로 끝나는 경우: 알 수 없는 인코딩 이름, 저장 폴더를 만들지 못함, 시작 페이지 열기 실패·타임아웃, 첫 페이지 수집 대상 불일치, 제외 문법 오류, 제외가 수집 대상을 가림 → 창은 `실패:` 줄로 보인다
  - 그 밖의 중단은 `중단:` 사유 줄로 알리고 받은 페이지 수를 돌려준다

| 옵션 | 기본 | 의미 |
| --- | --- | --- |
| maxPages | 0 | 0 이면 끝까지 |
| timeout | 15000 | 페이지 열기·변경 대기 상한 ms |
| delay | 0 | 페이지 간 대기 ms |
| digits / start | 4 / 1 | 파일 번호 자릿수 / 시작 번호 |
| titleSel | 없음 | 텍스트 헤더용 제목 셀렉터 |
| mode | text | text 또는 image |
| exclude | 없음 | 텍스트 모드 제외 셀렉터 |
| merge | false | 텍스트 모드 `_all.txt` |
| charset | 없음 | 메인 문서 인코딩 지정 |
| signal | 없음 | 사용자 중지 |

- 로그 줄의 머리말이 화면의 분류 기준이다 → `docs/spec_window.md` §4
  - 페이지 저장 줄: `[{받은 수}] … -> {파일}`
  - 사유 줄: `중단:` / 경고 줄: `경고:`·`주의:`·`건너뜀`

## 6. 동작 로직 및 정책

### 6.1 페이지 변경 판정 [FR#1, FR#4]

- 판정 값: 텍스트는 제외를 거친 innerText, 이미지는 주소 목록
- 받은 페이지 키 = sha1(주소 + 판정 값) → 본문 전체를 쌓지 않아 장편에서도 메모리가 늘지 않는다
- 주소가 바뀌었으면 받은 키 집합으로, 그대로면 첫 페이지 키와 넘어감 키 집합으로 순환을 판정한다

### 6.2 next 처리 순서 [FR#2, FR#3]

1. 요소 없음 → 셀렉터 불일치
2. 누를 수 있고 새 탭 링크가 아님 → 신뢰된 마우스 이벤트로 누른다
3. 누르지 못했거나 숨김·비활성 → href 가 있으면 주소 검사(`FR#17`) 뒤 이동
4. 그 밖 → 마지막 페이지

### 6.3 설계 결정

| 결정 | 선택 | 기각한 대안 | 근거 |
| --- | --- | --- | --- |
| `D#1` | 앱 내장 Chromium + CDP | HTTP 클라이언트, Playwright | SPA 페이지네이션은 실제 브라우저가 필요하다. Playwright 는 Electron 자신의 Chromium 에 붙지 못한다 |
| `D#2` | 신뢰된 마우스 이벤트(`Input.dispatchMouseEvent`)로 누른다 | JS `click()` | isTrusted 를 보는 사이트가 JS 클릭을 무시한다 |
| `D#3` | 평가는 `Runtime.evaluate` | `webContents.executeJavaScript` | 후자는 load 가 끝날 때까지 미뤄진다 → 응답이 멈춘 이미지 하나가 모든 평가를 막는다 |
| `D#4` | 제외 요소는 CSSOM 으로 요소마다 숨긴다 | 인라인 `<style>` 삽입 | 페이지 CSP 가 인라인 스타일을 막는다 |
| `D#5` | 인코딩 경고는 원래 바이트로 판정한다 | 브라우저가 고른 인코딩 이름 | 선언이 없을 때의 기본값이 환경에 따라 바뀐다 |
| `D#6` | 이미지는 페이지와 같은 세션의 `session.fetch` 로 받는다 | 렌더러 캐시, 별도 HTTP 클라이언트 | 쿠키·Referer 가 실려야 핫링크 판정을 통과한다 |
| `D#7` | 일시적 오류를 재시도하지 않는다 | 자동 재시도 | 차단 회피가 될 수 있다 (`BR#1`) → 사유만 정확히 남긴다 |
