# 패널 스펙

## 1. 개요

| 항목 | 값 |
| --- | --- |
| 문서명 | ariadne 사이드 패널 (UC5) |
| 작성일 / 최종 수정일 | 2026-11-14 / 2026-11-19 |
| 버전 | 2.0 |
| 기준 커밋 ID | 2d09b4e |

- **기능명:** 입력·실행·진행 표시·결과 요약·설정 저장
- **목적 (Why):**
  - 같은 사이트의 다음 편을 받을 때마다 셀렉터를 다시 넣지 않는다
  - 수백 페이지 수집이 어디까지 왔는지, 왜 멈췄는지 로그를 거슬러 읽지 않고 안다
  - 문제가 생기는 구조: 패널 화면은 패널 API 만 쓰고 검증·실행은 엔진이 한다 → 엔진의 로그 줄이 화면 상태의 유일한 원천이다

## 2. 목표 및 범위

### In Scope

- 입력 검증과 입력란 오류 표시
- 수집·probe·요소 선택 실행과 중지, 진행 상태·진행 막대·결과 요약
- 입력값·최근 URL·사이트별 셀렉터 저장
- 패널이 포커스를 잃은 동안 끝난 수집의 Chrome 알림
- 지금 탭 주소 따라가기, 출력 폴더 고르기, 툴바 아이콘으로 패널 열기

### Out of Scope

- 수집 동작 자체 → `docs/spec_collect.md`
- 셀렉터 후보 생성 → `docs/spec_selector.md`
- 여러 수집 동시 실행 (색인 제외 범위)

## 3. 요구사항

### 3.1 사용자 스토리

- `US#2` Chrome 사용자로서, 보던 탭을 떠나지 않고 받기 위해, 브라우저 옆 패널에서 입력·실행·진행 확인을 하고 지난 입력을 이어 쓰기를 원한다 [요구사항] → FR#1~FR#2, FR#4~FR#6, FR#8, FR#12~FR#20

### 3.2 기능 요구사항

- `FR#1` 시작 전에 입력을 검사하고, 틀린 입력은 해당 입력란에 표시한다 [as-built] (`NFR#6`)

  ```
  Given  URL 이 비었다
  Then   probe·선택기·수집 모두 거부한다
  Given  수집 대상 또는 next 가 비었다
  Then   수집만 거부하고 probe·선택기는 진행한다
  Given  숫자 칸에 숫자가 아닌 값, 알 수 없는 인코딩
  Then   거부한다
  When   거부된다
  Then   로그와 결과 영역에 사유가 나오고, 그 입력란이 aria-invalid 로 표시되며 포커스가 옮겨진다. 접힌 고급 옵션이면 펼친다
  ```

- `FR#2` 실행 중에는 상태·받은 페이지 수·마지막 파일·걸린 시간·진행 막대를 보인다 [as-built] (`NFR#6`)

  ```
  When   수집을 시작한다
  Then   상태가 '수집 중' 이 되고 페이지 로그 줄마다 페이지 수와 파일명이 갱신된다
  Given  최대 페이지 N
  Then   진행 막대가 받은 수 / N 을 보인다
  Given  최대 페이지 0
  Then   진행 막대는 진행 중임만 보인다
  ```

- `FR#4` 끝나면 결과를 로그 위에 한 줄로 요약한다 [as-built] (`NFR#6`)

  ```
  When   수집이 끝난다
  Then   완료·실패·중지, 받은 페이지 수, 걸린 시간이 보인다. 완료·실패는 멈춘 사유 한 줄을, 중지는 받은 파일이 남아 있다는 안내를 붙인다
  Then   같은 문구가 항상 렌더링된 알림 영역(role=status)에도 들어간다 → 스크린리더가 읽는다
  Given  받은 파일이 있다
  Then   요약에 고른 폴더 이름과 접두사가 붙는다 → 확장은 폴더를 열 수 없다
  ```

- `FR#5` 로그는 최근 2000줄만 두고, 경고·실패·완료 줄을 색과 줄 앞 표시로 구분한다 [as-built] (`NFR#6`)

  ```
  Given  2000줄을 넘는 로그
  Then   오래된 줄부터 지운다
  Given  '경고·주의·건너뜀' / '실패' / '완료' 로 시작하는 줄
  Then   warn / error / ok 로 분류되고 줄 앞에 '! ' / '× ' / '✓ ' 가 붙는다
  Given  로그·결과 문구에 페이지가 정한 셀렉터·글자가 섞여 온다
  Then   마크업으로 해석하지 않고 글자 그대로 보인다 (`NFR#13`)
  ```

- `FR#6` 첫 실행 전 빈 로그 자리에 첫 수집까지의 단계를 안내한다 [as-built] (`NFR#6`)

  ```
  Given  아직 실행하지 않았다
  Then   안내가 보인다
  When   실행한다
  Then   안내가 사라진다
  ```

- `FR#8` 수집을 시작한 URL 을 최근 10개까지, 호스트별 셀렉터 묶음을 최근 50개 호스트까지 남긴다 [as-built] (`NFR#10`)

  ```
  When   수집을 시작한다
  Then   URL 이 최근 목록 맨 앞에 오고(중복 제거), 그 호스트의 수집 대상·next·제목·제외·인코딩·모드가 사이트 설정에 남는다
  Given  URL 을 다른 호스트로 바꾼다
  Then   그 호스트의 사이트 설정으로 입력란과 모드를 채운다
  Given  같은 호스트 안에서 URL 을 바꾼다
  Then   채우지 않는다
  Given  저장된 사이트 설정·최근 목록에 틀린 형태가 섞였다
  Then   맞는 항목만 상한까지 쓴다
  ```

- `FR#12` 키보드만으로 실행·중지하고 포커스가 항상 보인다 [as-built] (`NFR#6`)

  ```
  When   Ctrl+Enter (macOS ⌘↵)
  Then   수집을 시작한다
  When   실행 중 Esc
  Then   중지한다
  Then   Tab 으로 옮긴 포커스가 눈에 보인다
  ```

- `FR#13` 모든 안내·오류·로그 문구는 경어체다 [as-built] (`NFR#6`)

- `FR#14` 사이드 패널은 수집이 끝날 때까지 상태를 맞게 보이고, 확장에서 쓸 수 없는 조작은 두지 않는다 [요구사항] (`NFR#6`, `NFR#17`)

  ```
  Given  이미지 모드
  Then   제목·제외·합치기 입력이 꺼진다 (텍스트 파일에만 쓴다)
  When   실행을 시작한다
  Then   고급 옵션을 접는다 → 로그 자리를 비운다
  Given  시작을 준비하는 중이다 (폴더 권한 요청 등)
  When   중지한다
  Then   실행하지 않고 '중지됨' 으로 끝난다
  Then   '브라우저 창 띄우기' 스위치와 '폴더 열기' 버튼은 없다
  When   수집이 예외 없이 끝난다
  Then   로그 끝에 '완료: {n}개 페이지' 가 붙는다
  ```

- `FR#15` 패널의 실행은 한 번에 하나다 [요구사항] (`NFR#6`)

  ```
  Given  수집·probe·선택기 중 하나가 진행 중
  Then   수집 시작·probe·요소 선택 버튼이 막히고 중지만 눌린다
  When   그 사이 패널 API 로 다른 실행이 들어온다
  Then   '이미 실행 중입니다.' 로 거부되고, 진행 중인 실행의 로그·선택값·중지는 그대로다
  ```

- `FR#16` 대기 중 주소 칸은 패널이 붙은 창의 지금 탭 주소를 따라간다 [요구사항] (`NFR#10`, `NFR#17`, `D#7`)

  ```
  When   패널을 연다 / 그 창에서 다른 탭으로 옮긴다 / 지금 탭이 다른 주소로 간다
  Then   주소 칸이 그 탭 주소로 바뀌고, 다른 호스트면 FR#8 처럼 사이트 설정을 채운다
  Given  지금 탭이 http·https 가 아니다 (확장 페이지), 또는 주소를 확장이 읽을 수 없다 (새 탭 페이지·about:blank 등 사이트 접근 권한 밖)
  Then   주소 칸을 바꾸지 않는다
  Given  사용자가 주소 칸을 고쳤다 (이어 받기 주소)
  Then   탭을 옮기거나 탭이 이동하기 전까지 고친 값이 남는다
  Given  실행 중
  Then   주소 칸이 바뀌지 않는다
  When   실행을 시작한다
  Then   그때의 지금 탭에서 주소 칸의 주소로 실행한다
  Given  지금 탭이 패널 화면 자신이다 (패널을 탭으로 열었다)
  Then   '수집할 탭이 없습니다.' 로 거부한다
  ```

- `FR#17` 수집은 사용자가 고른 폴더에 쓰고, 고른 폴더를 다음에도 쓴다 [요구사항] (`NFR#10`, `NFR#17`, `BR#2`, `D#8`)

  ```
  When   [폴더 선택] 을 눌러 폴더를 고른다
  Then   폴더 이름이 보이고, 패널을 다시 열어도 그 폴더가 남는다. 고르지 않았으면 '선택 안 됨' 이다
  Given  고른 폴더가 없다
  When   수집을 시작한다
  Then   '저장할 폴더를 골라 주세요.' 로 거부하고 [폴더 선택] 으로 포커스를 옮긴다. probe·선택기는 폴더 없이 진행한다
  Given  고른 폴더의 쓰기 권한이 없다 (권한을 언제 거두는지는 Chrome 이 정한다. 브라우저를 다시 켜도 남아 있을 수 있다)
  When   수집을 시작한다
  Then   Chrome 의 권한 요청을 띄우고, 허용하면 시작하고 거부하면 '폴더에 쓸 권한이 없습니다.' 로 거부하고 다시 고르라고 안내한다
  Then   접두사는 고른 폴더 안의 경로다 (기본값 page)
  ```

- `FR#18` 패널의 입력값·최근 URL·사이트 설정은 바뀔 때마다 `chrome.storage.local` 에 남고 다음에 패널을 열면 채운다 [요구사항] (`NFR#10`, `D#2`)

  ```
  When   입력값·모드·스위치를 바꾼다
  Then   저장되고, 패널을 다시 열면 그 값으로 채워진다 (주소 칸은 FR#16 이 먼저다)
  Given  저장된 값이 없거나 깨졌거나 모르는 키·틀린 타입이 있다
  Then   패널은 열리고 아는 키만 쓴다
  When   수집을 시작한다
  Then   최근 URL 과 그 호스트의 사이트 설정이 FR#8 의 상한까지 남는다
  Given  입력값 저장과 수집 시작의 저장이 겹친다
  Then   둘 다 남는다 → 저장은 차례로 한다
  ```

- `FR#19` 패널이 포커스를 갖고 있지 않을 때 끝난 수집은 Chrome 알림으로 결과를 알린다 [요구사항] (`NFR#16`)

  ```
  Given  패널 문서가 포커스를 잃은 채 수집이 끝난다
  Then   '수집 완료/실패/중지' 와 받은 페이지 수로 알린다
  Given  패널이 포커스를 갖고 있거나, probe·선택기가 끝난다
  Then   알리지 않는다
  ```

- `FR#20` 툴바의 확장 아이콘을 누르면 그 창의 사이드 패널이 열린다 [요구사항] (`NFR#17`)

## 4. 데이터 및 API 스펙

### 4.1 저장소

| 위치 | 키 | 내용 |
| --- | --- | --- |
| `chrome.storage.local` | `settings` | 아래 표의 형태 |
| IndexedDB `ariadne` / `handles` | `root` | 고른 폴더의 `FileSystemDirectoryHandle` |

| `settings` 의 키 | 형태 | 비고 |
| --- | --- | --- |
| url, sel, next, title, exclude, charset, prefix | 문자열 | 입력란 값 |
| max, start, digits, timeout, delay | 숫자 문자열 | 입력란 값 그대로 |
| mode | text 또는 image | |
| merge | boolean | |
| recent | 문자열[] | 최대 10, 최근 것이 앞 |
| sites | {호스트: {sel, next, title, exclude, charset, mode}} | 최대 50, 최근 것이 뒤 |

- 입력값 저장은 입력값만 바꾼다 → recent·sites 는 수집 시작 때만 바뀐다

### 4.2 패널 API

- 패널 화면은 패널 API(`globalThis.ariadne`)를 같은 문서에서 부르고, 로그·선택값은 `on('log' / 'pick')` 으로 받는다
- 로그 분류: 줄 머리 `완료` ok / `실패` error / `경고`·`주의`·`건너뜀` warn / `중단` info
- 진행: `[{n}] … -> {파일}` 줄에서 읽는다 → 화면용 이벤트를 따로 두지 않는다

## 6. 동작 로직 및 정책

### 6.1 실행 상태 [FR#2, FR#4, FR#15]

```
대기 ─시작→ 실행 중 ─거부→ 입력 확인
             ├─ 실패 줄 있음 → 실패
             ├─ 중지 → 중지됨
             └─ 그 밖 → 완료
```

- 화면은 시작 준비(입력 검사·폴더 권한)를 기다리기 전에 실행 상태로 바꾸고, 거부될 때만 되돌린다

### 6.2 설계 결정

| 결정 | 선택 | 기각한 대안 | 근거 |
| --- | --- | --- | --- |
| `D#1` | 진행 상태를 엔진 로그 줄에서 읽는다 | 화면용 진행 이벤트 | 로그와 상태가 어긋나지 않는다 |
| `D#2` | 설정을 바뀔 때마다(300ms 모아서) 저장한다 | 패널을 닫을 때 저장 | 패널이 비정상으로 닫혀도 입력이 남는다 |
| `D#3` | URL 을 쿼리까지 저장한다 | 쿼리 제거 | 연재물은 쿼리가 편·페이지를 가리킨다. 저장은 로컬뿐이다 (`BR#2`) |
| `D#4` | 사이트 설정은 호스트가 바뀔 때만 채운다 | URL 이 바뀔 때마다 | 같은 사이트에서 고쳐 쓰던 셀렉터를 덮지 않는다 |
| `D#5` | 로그 줄은 낭독하지 않고 상태·결과만 알림 영역으로 전한다 | 로그를 live region 으로 | 수백 줄이 쏟아질 때 낭독이 밀린다 |
| `D#6` | 입력 검사·설정 정리는 `core/form` 에 두고 패널이 부른다 | 패널 화면 안에 둠 | 화면 없이 빠른 단위 테스트로 검증한다 |
| `D#7` | 대기 중 주소 칸은 지금 탭을 따라간다 (탭 전환·탭 이동 때) | 패널을 열 때 한 번만 / 버튼으로 채우기 | 소유자 결정. 보던 탭이 곧 대상이다. 고친 이어 받기 주소는 탭을 옮기기 전까지 남는다 |
| `D#8` | 고른 폴더 핸들은 IndexedDB 에 두고, 권한은 수집 시작(사용자 클릭) 때 다시 묻는다 | `chrome.storage` / 매번 고르기 | `chrome.storage` 는 핸들을 담지 못한다(JSON). 권한 요청은 사용자 동작 안에서만 된다 |
| `D#9` | 알림 기준은 패널 문서의 포커스다 | 패널이 보이는지(visibility) | 패널이 보여도 페이지를 보고 있으면 결과를 놓친다 (`NFR#16`) |
